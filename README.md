# DrGraph V3

Creative design studio website — Next.js + TypeScript + Tailwind + Framer Motion.

## GitHub Pages preview

Create the repository as `drgraph` for the included Pages configuration.

After pushing to `main`:
1. Settings → Pages
2. Source → GitHub Actions
3. Open the Pages URL from the latest Actions deployment.

The included workflow builds `frontend` as a static export and publishes `frontend/out`.
