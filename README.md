# DrGraph Website

Initial production-oriented scaffold for DrGraph.

## Stack
- Frontend: Next.js + TypeScript + Tailwind CSS
- Backend: Java + Spring Boot
- Database target: PostgreSQL

## Current milestone
Frontend foundation:
- brand tokens
- responsive 12/8/4 column grid
- header
- hero
- about
- services
- selected works placeholder
- CTA
- footer

Backend foundation:
- Spring Boot application
- health endpoint
- CORS configuration placeholder
- package structure ready for modules

## Run frontend
npm install
npm run dev

## Run backend
./mvnw spring-boot:run
